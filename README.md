# INTERNSHIP: Student Management System

A web system for managing students, built during our Level 3 JavaScript internship. It gives students, parents, teachers and admins their own pages to sign up, log in and use a dashboard.

## Pages

| Role | Pages |
|---|---|
| Student | `student_signup.html`, `student_login.html`, `student_darshboards.html` |
| Parent | `parent_signup.html`, `parent_login.html`, `parent_darshboard.html` |
| Teacher | `teacher_login.html`, `teacher_darshboard.html` |
| Admin | `admin_signup.html` |

The repository also has demo videos (`student vd.mp4`, `supervisor vd.mp4`, `about vd.mp4`) and the images used on the pages.

## Run It

1. Download or clone the repository.
2. Open any login or signup page (for example `student_login.html`) in your browser.
